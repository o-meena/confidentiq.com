# confidentiq.com

The public website for ConfidentIQ, served by GitHub Pages at https://www.confidentiq.com.

- `index.html` - the home page
- `privacy.html` - the privacy notice
- `styles.css` - shared styles for both pages, including the light and dark themes
- `CNAME` - the custom domain GitHub Pages serves

To change the site, edit the files and push to `main`. GitHub Pages redeploys within a minute.
